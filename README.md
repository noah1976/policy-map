# 右派左派チェッカー v0.2

政党との一致度ではなく、政策を考えるときに重視している価値を独立して可視化する政治・政策診断のMVPです。

## 現時点の方針

- 右/左の単一スコアに押し込まない
- 自己認識（左 / 中道 / 右 / わからない）は採点に使わない
- 相反しない価値は独立して測る（例：防衛と外交、市場活力と再分配）
- 「判断できない」は中立回答と区別する
- 設問・採点ロジック・変更履歴を公開する
- 特定政党・候補者の支持や投票先の推薦を目的にしない

## v0.1 の価値項目

1. 再分配・公的保障
2. 市場競争・民間活力
3. 雇用・労働者保護
4. 転職・労働移動
5. 個人の自由
6. 安全・秩序
7. 防衛・抑止
8. 外交・協調
9. 多様性・制度変更
10. 伝統・継続性
11. 国際的な開放・交流
12. 主権・国内自立

## 注意

現状は各価値を1問だけで測る試作品です。公開用の正式診断にする前に、設問の中立性レビュー、反転テスト、回答分布の検証、必要に応じたA/Bテストを行う想定です。

## 開発

Node.js 22.22.2 で動作確認しています。必要条件は Node.js 20.19以降の20系、または22.12以降です。
[Viteの公式ガイド](https://vite.dev/guide/)も参照してください。

初回、または依存関係を入れ直す場合：

```bash
cd /Users/tomoyanikaidoh/git/policy-map-starter
nvm use
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

次回からは `npm ci` を省略できます。別のMacでNode.jsが未導入の場合は、先に `nvm install` を実行してください。
`nvm` が見つからない場合は、nvmを設定済みの通常のターミナルを開いてください。

ブラウザーで http://127.0.0.1:5173 を開きます。ファイルを保存すると画面へ自動反映されます。
停止は起動したターミナルで Ctrl+C。ポート使用中の場合は、既存のサーバーを確認するか別のポート番号を指定してください。

## 次に編集する場所

- `src/data/values.ts`：12個の価値項目・説明・グループ
- `src/data/questions.ts`：各価値に対応する仮設問
- `src/App.tsx`：初期画面、診断の進行、採点、結果表示
- `src/styles.css`：色、文字サイズ、余白などの見た目
- `src/data/model.ts`：価値や設問のデータ型

まず価値項目の定義を確認し、その後に対応する設問を見直します。
現状の採点は各価値につき1問を前提にしています。問数の表示はデータ件数から生成します。設問を増やす場合は採点処理も見直してください。

## ビルド

```bash
npm run build
```

`dist/` をCloudflare Pages等へデプロイできます。

## v0.2：独立評価と条件付きの選択

- 基本12問 → 分野別の解説・根拠・自己認識との比較 → 任意の追加4問。
- 基本回答の「条件による」「判断できない」は数値に変換しません。
- 追加質問は条件とA/B双方の目的・負担を提示し、中間・条件による・判断できないを区別します。
- 追加回答は価値スコアや左右判定に加算しません。
- 「かなり」「非常に」の回答から政治的な分類と重なる要素を説明します。未検証の暫定ルールで、左右を確定する尺度ではありません。
- 根拠回答を修正すると解説も更新します。全項目が高いことを矛盾や中道とは扱いません。
- `src/data/tradeoffs.ts`：追加質問と回答選択肢。
- `src/data/interpretation.ts`：分野別の説明ルール。
- `src/ResultReading.tsx`：説明・自己認識との比較・根拠回答への導線。
- 引き継ぐ方針、暫定仕様、未実装項目は `SPEC.md` に記録しています。
